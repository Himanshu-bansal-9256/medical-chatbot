# 🏥 MediCare AI — Medical Chatbot

A full-stack medical question-answering chatbot built using **Hybrid RAG (Retrieval-Augmented Generation)**, **Real-Time Streaming**, and **Interactive Chat History**.

The project uses comprehensive medical encyclopedia PDFs as its clinical knowledge source. The PDFs are tokenized into searchable vector embeddings and BM25 sparse indices, relevant information is retrieved and reranked for each user query, and a Groq LLM streams evidence-grounded answers directly into a modern React UI.

---

## ✨ Key Features

- ⚡ **Real-Time Streaming**: Server-Sent Events (SSE) stream tokens as generated by the Groq LLM with a typing cursor.
- 🔍 **Hybrid Retrieval**: Combines sparse BM25 keyword matching with dense FAISS vector embeddings across 11,600+ medical knowledge chunks.
- 🎯 **Cross-Encoder Reranking**: Re-scores top retrieved candidates using `ms-marco-MiniLM-L-6-v2` for high accuracy.
- 🔐 **JWT User Authentication**: Secure password hashing with bcrypt, persistent user sessions, and password change capabilities.
- 💬 **Chat History & Auto-Titles**: SQLite-backed chat sessions with LLM-generated 3-5 word concise titles.
- 🔗 **Shareable Chat Links**: Generate public read-only consultation links (`/?share=<token>`) to share discussions with colleagues or patients.
- 🎨 **Modern Clinical UI**: Clean dark/light theme toggle, shimmer skeleton loading, one-click answer copy, and auto-resizing input.
- 📖 **Rich Markdown Support**: Seamless rendering of clinical lists, tables, bold terminology, and sources citations using `react-markdown` and `remark-gfm`.
- 🛡️ **Rate Limiting & Validation**: Built-in `flask-limiter` protection (20 req/min for chat, 10 req/min for auth) and startup environment sanity checks.
- 🧪 **Automated Testing Suite**: Full Python unit tests covering auth, history CRUD, and sharing.

## 🚀 Quick Start

### Prerequisites

- Python 3.9+
- Node.js 18+
- Groq API Key ([Get one here](https://console.groq.com))

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Medical_chatbot.git
cd Medical_chatbot
```

### 2. Setup Backend

```bash
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Create .env file with your API key
cp .env.example .env
# Edit .env and set:
# GROQ_API_KEY=your_groq_api_key_here
```

### 3. Create Vector Database (First Time Only)

Place your medical PDF(s) in `backend/data/` then run:

```bash
cd backend
python create_memory_for_llm.py
```

### 4. Start Backend Server

```bash
cd backend
python app.py
```

The backend API will start at **http://localhost:5000**

### 5. Setup & Start Frontend

Open a new terminal:

```bash
cd frontend

# Install Node dependencies
npm install

# Start development server
npm run dev
```

The frontend will start at **http://localhost:5173**

### 6. Open the App

Open **http://localhost:5173** in your browser, register or login, and start exploring medical consultations!

## 🔌 API Endpoints

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `GET` | `/api/health` | No | System health check & models status |
| `POST` | `/api/auth/signup` | No | Register new user account |
| `POST` | `/api/auth/login` | No | User login (returns JWT token) |
| `GET` | `/api/auth/me` | Yes | Get authenticated user profile |
| `POST` | `/api/auth/change-password` | Yes | Update account password |
| `GET` | `/api/history` | Yes | List user's saved conversations |
| `POST` | `/api/history` | Yes | Create or update a conversation |
| `GET` | `/api/history/<id>` | Yes | Retrieve session transcript |
| `DELETE` | `/api/history/<id>` | Yes | Delete conversation |
| `POST` | `/api/history/auto-title` | Yes | Auto-generate 3-5 word title using LLM |
| `POST` | `/api/history/<id>/share` | Yes | Generate public share link token |
| `GET` | `/api/share/<token>` | No | Read-only shared consultation view |
| `POST` | `/api/chat` | Yes | Standard synchronous RAG question answering |
| `POST` | `/api/chat/stream` | Yes | Real-time SSE streaming RAG answer |
